# ClaudeTrans 翻译助手

一个简洁的桌面翻译工具，模仿 Claude 界面设计，支持中英文双向翻译。

## 功能特点

- 🎨 **模仿 Claude 界面**：深色主题，简洁美观
- 🔄 **智能翻译**：自动识别中英文，一键翻译
- 💬 **对话式展示**：翻译历史按对话形式展示
- ⚡ **响应快速**：基于 Electron + Vue3 开发

## 快速开始

### 开发模式

```bash
npm install
npm run dev
```

### 打包

```bash
npm run build
```

## 技术栈

- Electron
- Vue 3
- 有道翻译 API

## 使用说明

1. 在输入框输入中文或英文
2. 点击"翻译"按钮
3. 自动识别语言并翻译成对应语言
